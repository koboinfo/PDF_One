# リリースノート

## バージョン 1.0.0（初回リリース）

PDF One をご利用いただき、ありがとうございます。
本バージョンでは、PDFにまつわる作業を1つのアプリで完結させるための主要機能をすべて搭載しています。

**主な機能**

- PDFの結合・分割
- 画像からのPDF作成
- PDFの圧縮（低・中・高の3段階）
- ページの並び替え・回転・削除・抽出
- PDF ↔ Office（Word・Excel・PowerPoint）変換
- PDFからJPG画像への変換
- パスワードの設定・解除
- 指描画による電子署名
- 高精度OCR（日本語・英語対応）によるテキスト抽出
- テキスト透かしの追加
- 書類スキャン機能

**プライバシーへのこだわり**

すべての処理は端末内で完結し、ファイルが外部サーバーに送信されることはありません。広告SDK・解析SDKも組み込んでいません。

ご意見・ご要望がございましたら、設定画面よりお気軽にお問い合わせください。今後もアップデートを重ね、より使いやすいアプリを目指してまいります。

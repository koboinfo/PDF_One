# App Storeスクリーンショット レイアウト指示書

`docs/screenshot-copy.md` で確定済みのコピー（6枚構成）に対して、レイアウト・配色・グラフィック要素の
具体仕様を追加するもの。コピー内容自体はここでは変更しない。

## 1. キャンバスサイズ

| デバイス | 解像度（px） | 用途 |
|---|---|---|
| 6.7インチ | 1290 × 2796 | iPhone 15/16 Pro Max 等（必須） |
| 5.5インチ | 1242 × 2208 | iPhone 8 Plus 等（レガシー対応が必要な場合） |

- 書き出しは **PNG・アルファチャンネルなし・sRGB**。
- レイアウト比率（縦2分割の比率、余白率）は両サイズ共通。数値は6.7インチ基準で記載し、
  5.5インチは同じ比率でスケールする。

## 2. 縦2分割の基本グリッド（6.7インチ = 1290×2796基準）

```
┌─────────────────────────────┐  y=0
│                               │
│   セーフマージン 96px         │
│                               │
│   見出しコピー（1〜2行）      │  テキストゾーン
│   説明文（1行）               │  高さ: 約 780px（画面の28%）
│                               │
├─────────────────────────────┤  y=780
│                               │
│                               │
│   実機モックアップ            │  デバイスゾーン
│   （画面キャプチャ＋フレーム） │  高さ: 約 1968px（画面の70%）
│                               │
│                               │
└─────────────────────────────┘  y=2748
        下部マージン 48px
```

- 左右セーフマージン：96px（テキストのみ。デバイスモックアップは横幅いっぱいまで配置可、
  ただし左右最低32pxは背景を見せる）
- テキストゾームとデバイスゾーンの間：余白なしでよいが、デバイスモックアップの上端は
  角丸フレームの影がテキストに被らない位置（y=780目安）から開始する。

## 3. タイポグラフィ

| 要素 | フォント | サイズ | ウェイト | 行間 | 色 |
|---|---|---|---|---|---|
| 見出し（キャッチコピー） | Hiragino Sans（システム） | 84px | Heavy (W8) | 1.15 | `#1C293D`（Ink Navy、[color-palette.md](color-palette.md)参照） |
| 説明文 | Hiragino Sans（システム） | 40px | Medium (W5) | 1.4 | `#6E7380`（Secondary Slate） |

- 見出しは13〜18文字（`screenshot-copy.md`基準）。1行に収まらない場合は2行までで、
  2行目インデントなし・左揃え。
- 見出し・説明文とも **中央揃え**（デバイスモックアップも中央配置のため、テキストゾーンも中央揃えで統一）。
- 日本語の禁則処理（行頭に句読点を置かない等）を有効にする。

## 4. 背景・配色

- 基本背景：全6枚共通で `AppBackground` と同じパステルグラデーション
  `#EDF0F7`（上）→ `#DFE3ED`（下）を使用し、アプリ実機と地続きの印象にする。
- **アクセント演出（枚数ごとの差別化）**：各スクリーンショットのテーマ機能に対応する
  [color-palette.md](color-palette.md) の「機能別ティントカラー」を、背景グラデーションの奥に
  直径約1400pxの円形グロー（不透明度8〜12%、ぼかし大）として1つだけ配置し、単調さを避けつつ統一感を保つ。

| 枚数 | テーマ | グローに使うティント |
|---|---|---|
| 1枚目 | 全機能オールインワン | `#2673F2`（Accent Brand Blue） |
| 2枚目 | PDF↔Office変換 | `#948D68`（officeToPDF） |
| 3枚目 | OCR | `#6B5C51`（ocr） |
| 4枚目 | 署名・保護・透かし | `#5D777A`（protectPDF） |
| 5枚目 | プライバシー/ローカル処理 | `#626080`（signature系の落ち着いたトーンを流用、または無彩色`#6E7380`） |
| 6枚目（任意） | 結合・分割・圧縮 | `#626E8C`（merge） |

## 5. デバイスモックアップ

- フレーム：iPhone実機ベゼル（ベンダー提供のApple公式Product Photography素材、または
  Apple Design Resources配布のデバイスモックアップを使用。手描き/簡略化フレームは不可）。
- 角丸：実機に準拠（自作しない、フレーム素材のマスクをそのまま使用）。
- 影：`color: #000000 12%`, `blur: 64px`, `y-offset: 24px` をフレーム全体に適用し、
  背景から浮いている印象を出す（AppBackground上のカードUIと同じ浮遊感のトンマナに合わせる）。
- キャプチャ画面は各スクリーンショットの「画面」列（`screenshot-copy.md`参照）をそのまま使用。
  実機シミュレータでキャプチャする際はステータスバーを9:41固定・フル充電表示にする
  （Appleのマーケティング素材ガイドラインに準拠）。

## 7. 書き出しチェックリスト

- [ ] 6.7インチ・5.5インチとも同一レイアウト比率で書き出し済み
- [ ] 全ファイルPNG・アルファなし・sRGB
- [ ] 見出し文字数13〜18文字・説明文20〜30文字の範囲内（`screenshot-copy.md`基準を超えていないか）
- [ ] ステータスバーが9:41・フル充電表示になっているか
- [ ] 2枚目（PDF↔Office変換）は実変換ロジック実装・動作確認完了後に撮影・提出しているか
      （`app-store-metadata.md` の注意事項を参照）

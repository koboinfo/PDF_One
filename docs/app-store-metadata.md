## 概要（Description）

```
PDF One は、PDFの変換・編集・保護をすべて端末内で完結させるオールインワンPDFユーティリティです。
インターネット環境がなくても、ファイルを外部サーバーへ送信することなく、安心してPDFを扱えます。

■ PDF ↔ Office 変換
PDFをWord・Excel・PowerPoint形式に変換、また逆方向の変換にも対応。会議資料の再編集や、スキャンした書類の再利用がその場で完結します。

■ 結合・分割・圧縮
複数のPDFを1つに結合、ページ範囲を指定して複数ファイルに分割、画質を保ちながらファイルサイズを圧縮。メール添付やアップロード容量の制限にも柔軟に対応します。

■ ページ編集
ページの並び替え・回転・削除・抽出をグリッド画面で直感的に操作。不要なページの整理や必要なページだけの抽出も数タップで完了します。

■ 高精度OCR・テキスト抽出
Visionフレームワークによる日本語・英語対応OCRで、スキャンした紙文書や画像PDFからテキストを抽出。検索可能なドキュメントとして再活用できます。

■ 電子署名・パスワード保護・透かし
指で描いた署名をPDF上の任意の位置に配置。契約書や申請書へのパスワード設定・解除、社外秘資料への透かし追加にも対応し、書類のセキュリティを強化します。

■ 画像からPDF作成・PDFからJPG変換
カメラで撮影した書類やライブラリの画像をまとめてPDF化。逆にPDFの各ページをJPG画像として書き出すことも可能です。

■ プライバシー第一の設計
広告SDK・解析SDKを組み込んでおらず、処理したファイルが外部サーバーに送信されることはありません。すべての変換・編集処理は端末内で完結します。

こんなシーンで活躍します：
・出張先や移動中にWord/Excelの資料をPDFで受け取り、その場で編集したいとき
・紙の書類をスキャンしてテキスト化・整理したいとき
・契約書に電子署名をして、そのまま共有したいとき
・大容量PDFを圧縮してメール添付したいとき

シンプルな操作画面と高速なオンデバイス処理で、PDFにまつわる面倒な作業をPDF One 1つで解決します。
```

## 概要（Description）

```
PDF One は、PDFの変換・編集・保護をすべて端末内で完結させるオールインワンPDFユーティリティです。
インターネット環境がなくても、ファイルを外部サーバーへ送信することなく、安心してPDFを扱えます。

■ PDF ↔ Office 変換
PDFをWord・Excel・PowerPoint形式に変換、また逆方向の変換にも対応。会議資料の再編集や、スキャンした書類の再利用がその場で完結します。

■ 結合・分割・圧縮
複数のPDFを1つに結合、ページ範囲を指定して複数ファイルに分割、画質を保ちながらファイルサイズを圧縮。メール添付やアップロード容量の制限にも柔軟に対応します。

■ ページ編集
ページの並び替え・回転・削除・抽出をグリッド画面で直感的に操作。不要なページの整理や必要なページだけの抽出も数タップで完了します。

■ 高精度OCR・テキスト抽出
Visionフレームワークによる日本語・英語対応OCRで、スキャンした紙文書や画像PDFからテキストを抽出。検索可能なドキュメントとして再活用できます。

■ 電子署名・パスワード保護・透かし
指で描いた署名をPDF上の任意の位置に配置。契約書や申請書へのパスワード設定・解除、社外秘資料への透かし追加にも対応し、書類のセキュリティを強化します。

■ 画像からPDF作成・PDFからJPG変換
カメラで撮影した書類やライブラリの画像をまとめてPDF化。逆にPDFの各ページをJPG画像として書き出すことも可能です。

■ プライバシー第一の設計
PDFファイルなどの処理データが外部サーバーに送信されることはなく、すべての変換・編集処理は端末内で完結します（詳しくはプライバシーポリシーをご確認ください）。

こんなシーンで活躍します：
・出張先や移動中にWord/Excelの資料をPDFで受け取り、その場で編集したいとき
・紙の書類をスキャンしてテキスト化・整理したいとき
・契約書に電子署名をして、そのまま共有したいとき
・大容量PDFを圧縮してメール添付したいとき

シンプルな操作画面と高速なオンデバイス処理で、PDFにまつわる面倒な作業をPDF One 1つで解決します。

■ PDF One Pro（サブスクリプション）
電子署名・OCR・透かし・PDF↔Office変換は、月額480円・年額4800円のPDF One Pro（いずれも7日間の無料トライアルあり）でご利用いただけます。購読は自動更新され、期間終了の24時間前までにキャンセルしない限り自動更新されます。管理・解約は端末の設定＞Apple ID＞サブスクリプションから行えます。
```

## サブスクリプション（Pro プラン）に関する記載 — 価格・期間は確定、実機確認待ちで申請不可

2026-08-11時点で、機能ゲート方針・価格・無料トライアルは以下の通り確定し、概要文（上記）にも反映済み。Guideline 3.1.2(a)が求める**期間・価格・機能内容の明記**はこれで満たしている。

- **機能ゲート方針**: 電子署名・OCR・透かし・PDF↔Office変換（PDF→Office/Office→PDFの2ツール）の計5ツールをPro限定とし、それ以外（結合・画像→PDF・圧縮・ページ編集・PDF→JPG・分割・パスワード設定）は無料のまま。`ToolsView`でのタップ時ガードと、各Pro対象View自身によるガードの二重構成で配線済み。
- **価格・期間**: 月額`com.pdfone.pro.monthly` 480円 / 年額`com.pdfone.pro.yearly` 4,800円（`Subscriptions.storekit`で設定した値。App Store Connect側の実際の価格設定時にこの値と一致させること）
- **無料トライアル**: 月額・年額とも7日間
